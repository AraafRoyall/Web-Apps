# Royall UI Engine

A small universal UI/theme layer for Royall GitHub Pages projects.

## Files
- `royall-ui.css` — fixed visual theme and reusable classes.
- `royall-ui.js` — reusable UI helpers and components.
- `sample.html` — independent test/demo page.

## Core
Main layout, app header, helper/status strip, buttons, boxes, inputs, text areas, counters, chips, bottom action bar, FAB, confirmation dialogs, choice dialogs, prompt dialogs, toast, copy/paste, download, clear confirmation and expand/collapse.

Application-specific crypto/business logic does NOT belong here.
